## Part 4: Key Interview Talking Points & Screening Prep

When ChillBase invites you to an interview, expect deep dives into these specific areas:

### 1. "How do you actually take 'vibe coded' scripts from marketing and make them maintainable?"
- **The Answer:** 
  *"You don't rewrite it into standard Java or old-school monoliths. You wrap it in an agent-maintainable harness:
  1. **Containerize & Isolate:** Put each tool in a standardized Docker container so dependencies never collide.
  2. **Schema Contracts:** Enforce Pydantic / TypeScript Zod schemas on inputs and outputs so hallucinations or malformed JSON fail fast.
  3. **Agent Rulesets (`AGENTS.md` / `CLAUDE.md`):** Use Initra's philosophy—commit strict architectural guidelines into the repo so when Claude Code or another agent modifies the tool, it adheres to the existing conventions.
  4. **Test Harness:** Create deterministic mock test cases that an agent can run in bash to verify its own diffs before opening a PR."*

### 2. "How would you set up Dify + Slack + ClickHouse with MCP?"
- **The Answer:**
  *"Dify acts as the visual orchestration layer and Slack webhook listener. For ClickHouse, we build or connect an MCP (Model Context Protocol) server running over stdio or internal SSE that exposes safe, read-only analytical queries with parameter validation (e.g. querying campaign spend, CPI, ROAS, retention cohorts by day/country).
  Slack bots receive prompts, execute authorized MCP tools, format summaries into Slack Block Kit cards, and post alerts when CPA exceeds thresholds. Everything runs behind an internal VPC with zero public inbound ports exposed."*

### 3. "How do you control LLM spend across marketing teams?"
- **The Answer:**
  *"Three layers:
  1. **Gateway Proxy (e.g. LiteLLM / OpenRouter / Custom Reverse Proxy):** All Dify and internal scripts hit an internal proxy with per-user/per-project API keys.
  2. **Hard & Soft Quotas:** Daily/monthly spend limits with Slack webhook warnings at 75% and automatic model downgrade (e.g., Sonnet 3.5 -> Haiku 3.5 or Gemini 2.5 Flash) if a rogue loop runs.
  3. **Caching & Semantic Deduplication:** Cache repetitive marketing queries and evaluation runs to avoid paying twice for identical analytical prompts."*
